### 🧭 Rules I build by

- Default deny, then earn every allow.
- If a scanner can't fail the build, it's decoration.
- The safest secret is the one that doesn't exist.
- Budgets are security controls. A runaway bill is an incident.
- If it needs me in the room to be understood, it isn't done.
