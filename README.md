# 💫 About Me

Full-Stack Developer with almost 10 years of experience, now focused on Cloud Security and DevSecOps — building infrastructure-as-code that bakes security and cost guardrails into the deployment pipeline itself, rather than bolting them on afterward. Background spans full-stack development and UX/UI design, which now shows up as an emphasis on clean, reviewable module structure over one-off scripts.

# 🔐 Featured Cloud Security Projects

A 3-phase Terraform security portfolio on Azure, plus a Google Cloud re-implementation of the same baseline:

* **[Project Vault](https://github.com/luis-troccoli/project-vault)** — Phase 1: network + Key Vault fundamentals.
* **[Secure Cloud Foundation](https://github.com/luis-troccoli/secure-cloud-foundation)** — Phase 2: OIDC-federated CI/CD with a blocking Checkov gate.
* **[FinTech-Guard-OS](https://github.com/luis-troccoli/fintech-guard-os)** — Phase 3: modular Terraform (network/security/finops) with a progressive FinOps budget guardrail.
* **[FinTech-Guard-Native](https://github.com/luis-troccoli/fintech-guard-native)** — the same Phase 3 baseline, ported to GCP with Workload Identity Federation and native Google Cloud services.
* **[AWS Application Load Balancer](https://github.com/luis-troccoli/aws-app-load-balancer)** — step-by-step ALB setup: target groups, health checks, listener/HTTPS configuration.
