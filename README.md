### 📕 About me

I started in UX/UI design and web development, then spent the last 6+ years in cloud infrastructure, SOC operations and security automation. I build infrastructure-as-code where security and cost control are first-class requirements, not something bolted on the week before a compliance review: modular Terraform, default-deny networking out of the box, secrets in each platform's native vault, and CI/CD pipelines with a security gate that actually stops bad code.

I build the same baseline on more than one cloud to keep it portable instead of locked into one vendor, and I document where a guardrail doesn't translate 1:1 instead of pretending it does.

The design background shows up as infrastructure that's not just secure but reviewable: clear module boundaries, no hidden defaults, nothing you need me in the room to understand.
