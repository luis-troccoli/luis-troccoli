## Luis Troccoli
**Cloud Security Engineer | DevSecOps**

I design and secure cloud infrastructure on Azure, AWS and Google Cloud, with a focus on infrastructure as code, CI/CD security and cost governance. Background in UX/UI design and web development, followed by 6+ years in cloud infrastructure, SOC operations and security automation.

### Focus areas
- **Infrastructure as Code:** modular Terraform with secure defaults and default-deny networking
- **CI/CD security:** OIDC and Workload Identity Federation instead of static credentials; Checkov as a blocking gate
- **Security operations:** alert triage and investigation in Splunk and Microsoft Sentinel
- **FinOps:** budget guardrails and progressive cost alerting built into the infrastructure
