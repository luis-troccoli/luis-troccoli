# 💫 About Me

Full-Stack Developer with over 10 years of experience, now specialized in Cloud Security and DevSecOps. I design and build infrastructure-as-code that treats security and cost control as first-class requirements — not an afterthought bolted on before a compliance review. That means modular Terraform, default-deny network posture out of the box, secrets managed through the platform's native vaulting service instead of hardcoded values, and CI/CD pipelines with a blocking security-scan gate rather than a soft warning that gets ignored.

Before specializing in cloud security, I spent most of my career as a full-stack developer with a strong UX/UI design background — that combination now shows up as an emphasis on infrastructure that's not just secure, but genuinely reviewable: clear module boundaries, documented tradeoffs, and no hidden defaults.

I've built this out across multiple cloud providers (Azure and Google Cloud) to keep the same security baseline portable rather than locked into one vendor's tooling.
